## Agent skills

### Issue tracker

Simpan spesifikasi dan tiket sebagai file Markdown di `.scratch/<feature-slug>/`. Lihat `docs/agents/issue-tracker.md`.

### Triage labels

Gunakan lima label triase default yang tercantum di `docs/agents/triage-labels.md`.

### Domain docs

Gunakan tata letak `single-context`: `CONTEXT.md` di root dan ADR di `docs/adr/`. Lihat `docs/agents/domain.md`.

## Bahasa

Gunakan Bahasa Indonesia untuk komunikasi dan dokumentasi, kecuali diminta lain. Pertahankan nama skill, label, status, identifier, dan istilah teknis sebagaimana diperlukan.
