# ADR-0010: Handoff admin tanpa riwayat percakapan

Status: accepted

Pesan handoff ke admin memuat nomor pengirim, alasan handoff, penanda **PEMBARUAN** bila relevan, dan Ringkasan Kebutuhan bila tersedia; riwayat percakapan tidak disertakan. Handoff tanpa Permintaan Tindak Lanjut tetap mengirim nomor dan alasan saja. Transkrip lokal tetap dicatat terpisah sesuai ADR-0007. Keputusan ini memperbarui ketentuan isi pesan di ADR-0006, tanpa mengubah pilihan WhatsApp sebagai kanal admin.
